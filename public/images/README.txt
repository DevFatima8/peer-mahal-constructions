TAREEQA (3 steps):
  1. File ka naam neeche di gayi list se rakhein
  2. File isi folder (public/images/) mein rakh dein
  3. Rebuild:  npm run build

Extension koi bhi chalega : .jpg .jpeg .png .webp .avif .svg
Bade/chhote huroof (case) se koi farq NAHI parta.
Naam mein space ya brackets na rakhein.

  logo-white       <- Footer ka safed logo (optional)

  commercial       <- Plaza / dukan / office     (1200x800)

  supervision      <- Site supervision / survey  (1200x800)
  drawings         <- Naqshe / blueprints        (1200x800)
  cta-bg           <- Neeche dark banner ka bg   (1920x1080 dark)
